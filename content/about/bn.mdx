# Free Harmonium সম্পর্কে

Free Harmonium একটি browser-based harmonium, যা software install না করেই বাজানো যায়। এটি quick practice, melody exploration, pitch reference এবং real harmonium কাছে না থাকলে সহজে ব্যবহার করার জন্য তৈরি।

আপনি computer keyboard, touch screen অথবা compatible MIDI keyboard দিয়ে বাজাতে পারেন। এটি real instrument replace করার জন্য নয়, বরং দ্রুত ব্যবহারযোগ্য practice tool হিসেবে তৈরি।

## কী করতে পারবেন

- Browser-এ সরাসরি harmonium বাজাতে পারবেন।
- Computer keys, touch এবং MIDI input ব্যবহার করতে পারবেন।
- Swaram notation practice করতে পারবেন।
- Volume, octave, transpose, sustain এবং reverb adjust করতে পারবেন।
- প্রথম note বাজালেই samples load হবে।

## কেন এটি দরকার

Real harmonium-এর air, reeds, wood এবং touch আলাদা অভিজ্ঞতা দেয়। Free Harmonium তা পুরোপুরি replace করে না। এটি pitch check, sargam practice, melody testing এবং vocal riyaz-এর জন্য practical companion।

## Feedback

Keyboard layout, sound behavior, MIDI handling অথবা language content-এ সমস্যা দেখলে feedback স্বাগত।
