# Free Harmonium के बारे में

Free Harmonium एक browser-based harmonium है जिसे बिना software install किए बजाया जा सकता है। यह quick practice, melody exploration, pitch reference और उन समयों के लिए बनाया गया है जब real harmonium पास न हो।

आप computer keyboard, touch screen या compatible MIDI keyboard से बजा सकते हैं। इसका उद्देश्य real instrument को replace करना नहीं, बल्कि एक हल्का और तुरंत उपलब्ध practice tool देना है।

## आप इससे क्या कर सकते हैं

- Browser में सीधे harmonium बजाएं।
- Computer keys, touch और MIDI input इस्तेमाल करें।
- Swaram notation practice करें।
- Volume, octave, transpose, sustain और reverb adjust करें।
- पहला note बजाते ही samples load करें और practice शुरू करें।

## यह क्यों उपयोगी है

Real harmonium की हवा, reeds, लकड़ी और touch अलग अनुभव देते हैं। Free Harmonium उन चीजों को पूरी तरह copy नहीं करता। यह pitch check, sargam practice, melody testing और vocal riyaz के लिए practical companion है।

## Feedback

Keyboard layout, sound behavior, MIDI handling या language content में कोई समस्या दिखे तो feedback स्वागत है।
